# 更新日志

## 0.0.1

PMail Pro 首个版本。

### 新功能与变化

1. **新版邮箱界面**：React SPA 提供桌面三栏、移动端布局、暗色模式、虚拟列表、星标和服务器草稿。
2. **域名 DNS 向导**：逐条检查 MX、地址、SPF、DKIM、DMARC 等，提示如何合并 SPF，并导出 BIND 区域片段。
3. **首次注册密钥**：空库且未设置 `PMAIL_ADMIN_PASSWORD` 时，通过 `docker compose exec pmail cat /work/config/registration_key` 读取一次性密钥（默认不打印到日志）并在 HTTPS 网页注册。
4. **中文与英文提示**：后端按用户语言或请求协商返回提示，退信也按收件用户偏好生成。
5. **移除插件**：不再加载可执行插件，插件设置、微信推送及外部垃圾邮件分类插件停用。内置 catch-all SPF/DKIM 过滤不变。
6. **代码邮件与附件预览**：保留常见代码结构、缩进和补丁；支持 Markdown 围栏、代码高亮及安全的文本附件预览。
7. **前后端独立构建、同镜像部署**：React 与 Go 以 OpenAPI 为契约，网页产物运行时从 `/work/web` 加载，不再嵌入 Go 二进制。

8. **入站分析**：按用户配置垃圾评分及贝叶斯学习；代码风险识别、危险附件确认、验证码提取（含跨行和取件码）；对合法投递超时降级，不丢信。
9. **Telegram 私聊推送**：安全配置机器人、一次性绑定，支持分组、验证码、简要预览及免打扰。无需公网 webhook。
10. **更新检查与发布日志**：查看稳定版本及安全渲染的 Markdown 更新说明；默认保留手动更新，可选用私有 Compose sidecar 更新 PMail 服务。
11. **富文本写信**：内嵌图片随邮件发送，草稿保留引用；新增按发件地址选用的签名和默认签名。

### 修复与兼容性

- 重写 POP3 服务端会话：邮件使用连续会话序号，`UIDL` 保持稳定；`DELE` 在 `QUIT` 时提交，`RSET` 可撤销。
- API 新增带时区的 RFC3339 `*_iso` 字段，旧时间字段保留兼容。新版界面优先使用 `*_iso`，避免按浏览器时区误读旧时间。
- DNS 向导本地化记录用途和状态；草稿、本机发件不再显示入站伪造警告。改善暗色模式对比度，并修复 Patch 差异视图误显示的尾随空行。
- 前端生产依赖升级至 Zod 4、TipTap 3，同步升级表单解析器并更新依赖锁文件。

- 审计加固：收紧 Cookie/CSRF、API Token 权限与期限、附件授权、SMTP/POP3 认证、会话撤销、外发连接策略及凭据绑定；限制输入体积并修复 IMAP 邮箱 UID 和删除事务。
- 性能：列表投影与游标分页、附件分块、IMAP/POP3 元数据批读、队列共享原文、增量配额、分组/地址批读及 Token 写入节流。

### 升级注意事项

- 先备份数据库与配置卷。已有账号直接登录，不重新注册。`initial_admin_password` 不再生成；已有文件不会自动删除。
- 不再读取插件配置，不做破坏性数据迁移。若依赖插件通知或分类，请在升级前安排替代方式。
- 附件迁至 `/api/attachments/{id}` 和 `/api/attachments/download/{id}`，兼容旧 `/attachments/*`；文本预览为 `/api/attachments/preview/{id}`。
- 在线更新器默认关闭，启用需信任拥有 Docker socket 的 sidecar。共享队列和凭据迁移的回滚应使用升级前备份。
